# Thông tin StyleID gốc

StyleID được giới thiệu trong công trình **StyleID A Perception Aware Dataset and Metric for Stylization Agnostic Facial Identity Recognition**, SIGGRAPH 2026 và ACM TOG Journal Track.

- [Bài báo](https://arxiv.org/abs/2604.21689)
- [Trang dự án](https://kwanyun.github.io/StyleID_page/)
- [Model chính thức trên Hugging Face](https://huggingface.co/kwanY/styleid)
- [StyleBench S](https://huggingface.co/datasets/kwanY/stylebench-s)

## Điều kiện sử dụng trong tài liệu gốc

Các thông báo sau được giữ từ README nguồn.

- StyleID is released for non-commercial research use.
- Do not use FFHQ-derived data for biometric human recognition.
